# Resume Maker

## Overview 
> This is a Platform for Ticketing system for Post an issue and finding solutions which is based on NodeJs Technology where one user  finds the solution of any issue or question by post in the platform. Also if the user knows the solution of the question then give the answer to that question to help others. This project is an API based pure backend side project. We can use these APIs to develop full stack projects.


## Installation

```console
npm install
```


## Run

> To build in development environment

```console
npm build
```

> To start server

```console
npm start
```

> To start server in development environment

```console
npm run dev
```

## Packages used

* express
	* express is used for server.
* sequelize
	* sequelize is a ORM used for database operation.
* mariadb
	* mariadb is database that is used for storing data
* ejs
	* to give support for ejs files
* html-pdf
	* to convert html files to pdf
